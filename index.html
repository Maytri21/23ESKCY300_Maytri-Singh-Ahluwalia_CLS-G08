Interactive Diffie-Hellman Key Exchange

Educational demonstration of public-key agreement

1. Public parameters

Choose a small prime number p and a generator candidate g. Both values are public and may be known to everyone.

For this teaching demo, p must be prime and 1 < g < p. The app checks primality, but does not prove that g generates the full multiplicative group.

2. Alice's values

Public value A = ga mod p
—

3. Bob's values

Public value B = gb mod p
—

4. Calculate the shared secret

Alice computes K₁ = Ba mod p. Bob computes K₂ = Ab mod p.

Enter valid values, then run the exchange.
  1. Public parameters: p and g.
  2. Alice publishes A; her private value a stays with Alice.
  3. Bob publishes B; his private value b stays with Bob.
  4. Both calculate the shared secret independently.

5. Security observations

  • Private values should never be transmitted.
  • Diffie-Hellman establishes a shared value; it does not by itself authenticate the other party.
  • An unauthenticated exchange can be vulnerable to a man-in-the-middle attack.
  • Real systems use well-reviewed cryptographic libraries, strong parameters, authentication and key derivation. This small-number demo is not secure for real information.
